---
name: qq
description: Handle prompts containing a mixed list of questions and instructions by answering every question satisfactorily before any implementation begins. Use when the user wants discussion and explicit approval to precede implementation.
---

Answer every question to a satisfactory degree and address the instructions, but explicitly await the user's approval before starting implementation. When a question implies an action, briefly describe the proposed solution and, unless conflicting instructions are given, treat approval as authorization to implement that solution.
